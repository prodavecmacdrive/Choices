# Playable Ads Agent Template

Agent-oriented project documentation and Antigravity configuration for a reusable HTML5 playable ads framework.

## Structure

- `.agents/rules/` — always-relevant project rules.
- `.agents/skills/` — specialized workflows.
- `docs/` — persistent project knowledge.

## First step

Run the `project-context` workflow against the actual repository.

Do not treat the placeholder platform requirements as verified until they have been checked against current official sources.

## Intended workflow

1. Understand context.
2. Inspect existing implementation.
3. Implement the smallest required change.
4. Build when relevant.
5. Validate the playable.
6. Update durable project knowledge.
7. Leave Git commit/push decisions to the user.
